# Bootstrap

Orient yourself to this repository before editing.

1. Read `AGENTS.md`, `README.md`, and `docs/agent/CONTEXT.md`.
2. Run `git status --short` and preserve all existing user changes.
3. Inspect the repository tree, dependency manifests, and relevant tests.
4. Identify the current stack and the documented verification commands.
5. Briefly summarize the project state, the files likely involved, and any
   assumptions before beginning the requested work.

Do not install dependencies, change external state, or perform destructive
operations unless the task requires it and the user has authorized it.
